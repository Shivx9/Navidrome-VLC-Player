# Navidrome VLC Player

This is a project to integrate wifi-enabled microcontrollers as media remote for a server hosting Navidrome, using independent media playback to bypass cryptic permission issues presented when working with Navidrome's Jukebox Mode in Linux.

Server stack - Python3 (lightweight Flask app with inline VLC for managing playback)
Client stack - ESP32-S3 (or any other sufficient equivalent) + other hardware (to be listed)

Development and documentation still in progress
